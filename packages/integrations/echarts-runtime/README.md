# @chartguard/runtime-echarts

Optional opt-in runtime validation wrapper for echarts.

**Status:** see [`docs/00-status.md`](../../../docs/00-status.md) and [`docs/03-packages.md`](../../../docs/03-packages.md) for completed vs planned functionality.

Build: `npm run build -w @chartguard/runtime-echarts` (except CLI which is native ESM). Test: `npm run test -w @chartguard/runtime-echarts`.

Public API is declared in `src/index.ts` and exported via package `package.json`.
